A chave secreta, arquivar

A chave de quem integra pelo servidor, o arquivar e os domínios.

Em resumo
  • A chave secreta nasce sob pedido e aparece uma vez só.
  • Trocar revoga a anterior na hora, e ela fica como histórico.
  • Relato de domínio desconhecido espera até alguém permitir ou bloquear.

Gerar a chave secreta

Em Chaves → Integração avançada, clique em Gerar chave secreta:

POST /projects/2be49b28-.../keys/secret
{
  "Success": true,
  "Message": "Chave secreta gerada. Ela não será exibida de novo.",
  "Data": { "PublicId": "4d0e...", "Value": "sk_EXEMPLO2...", "Prefix": "sk_EXEMPLO2",
            "CreatedAt": "2026-10-07T14:02:11Z" }
}

É a única vez que o valor sai do servidor: o banco guarda só o hash. A tela mostra para copiar e avisa antes de você sair.

Hoje nenhuma rota da API aceita a chave secreta: por enquanto, ela só se gera e se troca.

Trocar a chave secreta

Com uma secreta valendo, a mesma rota (Gerar nova chave) revoga a anterior e devolve a nova uma vez. A lista fica assim:

Secret sk_EXEMPLO2 ativa (a nova) Public pk_EXEMPLO1 ativa Secret sk_EXEMPLO1 revogada (fica como histórico)
Trocar quebra as integrações que usam a chave antiga

É imediato e sem desfazer. A antiga fica para investigar um incidente depois.

Arquivar

PATCH /projects/2be49b28-...
{ "Status": "Archived" }

O que não vier no corpo fica como está. O projeto continua consultável, só para de aceitar coisa nova. Renomear e arquivar ficam na tela Projeto (arquivar no fim dela).

Permitir ou bloquear um domínio

A tela Domínios começa por Aguardando liberação: relatos de domínios não autorizados, que o time só vê depois de decidir. O sino avisa uma vez por domínio.

GET  /projects/2be49b28-.../origins/pending
POST /projects/2be49b28-.../origins          { "Domain": "loja.com", "AllowsSubdomains": false }
  • Permitir autoriza o domínio, e os relatos retidos entram no topo do quadro.
  • Bloquear apaga os retidos de vez.
  • O relato sem domínio tem Liberar e Apagar de vez só para ele (origins/pending/release e /delete).
  • O relato de teste do próprio painel nunca espera.

Embaixo, Domínios que mandaram relatos mostra a situação de cada um. Um domínio já coberto por outro bloqueio (app.loja.com, com *.loja.com bloqueado) mostra Desbloquear *.loja.com no lugar de Permitir (a API recusa com 409).

POST /projects/2be49b28-.../origins/blocked
{ "Domain": "copia-da-loja.com", "IncludesSubdomains": false }

Vale na hora: o próximo relato é recusado e a ferramenta deixa de abrir. Os cards que já tinham entrado ganham a marca Origem bloqueada, e em Bloqueados você escolhe:

  • Revisar na lista abre o Trabalho só com eles;
  • Manter tira a marca de todos;
  • Apagar de vez pede para escrever o domínio ou "apagar" antes.

A lista de autorizados começa vazia e aceita localhost:3000 (a porta conta) e *.loja.com para subdomínios. Permitir um bloqueado tira o bloqueio e autoriza. Para só tirar o bloqueio, use Desbloquear, e o próximo relato de lá volta a esperar liberação.
