4. O primeiro relato chegando

Com a chave pública em mãos, o site do cliente cola uma linha. É a única coisa nossa que fica no HTML dele:

<script src="https://.../v1/pds.js" data-key="pk_1R0KtQwz" defer></script>

O que acontece daí em diante não passa por sessão nenhuma:

o script cria um iframe apontando para o NOSSO domínio — invisível ↓ a página manda a chave, a rota e a origem por postMessage ↓ GET /public/widget-settings → este endereço pode abrir? como o cliente quer o quadro? ↓ o quadro pede para aparecer, e só então o gatilho surge no canto ↓ quem preenche o formulário está dentro do iframe, na nossa origem ↓ POST /public/reports → confere o endereço de novo, protocolo + token

O formulário nunca toca a página do cliente, e a página do cliente nunca toca o formulário: são origens diferentes, e a única coisa que atravessa é o que as duas pontas conferiram.

Por que o quadro nasce invisível

O pedido para aparecer é a mesma mensagem que informa tamanho e canto, e o quadro só a manda depois de ler a configuração. Uma regra resolve quatro coisas: ele aparece já no canto certo em vez de pular de lado; a ferramenta desligada simplesmente nunca pede e nunca aparece; o rótulo do cliente não pisca, porque nada é desenhado com os padrões para ser trocado na frente de quem já estava lendo; e um quadro que não carregou some, em vez de deixar uma pílula vazia parada no site.

O preço é uma ida à rede antes do gatilho aparecer. Se essa leitura falhar, valem os padrões e a ferramenta abre assim mesmo — "não consegui saber" não pode virar "não apareço", porque é justamente quando algo quebrou que alguém precisa avisar.

Por que o relato carrega a chave no corpo, e não um cabeçalho

Não há credencial nesta requisição — a chave pública não autentica ninguém, ela só diz para qual projeto o relato vai. Tratá-la como cabeçalho de autorização convidaria o próximo leitor a achar que ela protege alguma coisa.

A origem é conferida, e continua não sendo prova

O campo Origin é declarado pela própria página que embutiu a ferramenta, e é comparado com a lista de project_origins nas duas rotas que a ferramenta usa. Projeto com a lista vazia aceita qualquer endereço, e quem não declara endereço passa.

Como quem declara é o carregador, que é código nosso, a chave copiada para outro site é pega — e é para isso que a lista serve. Quem chamar a API sem passar pela ferramenta declara o que quiser: grade de proteção, não muro. O muro é o frame-ancestors montado da mesma lista, que impede o quadro de abrir fora dela e precisa de um servidor servindo o documento do quadro — chega com o domínio próprio.
