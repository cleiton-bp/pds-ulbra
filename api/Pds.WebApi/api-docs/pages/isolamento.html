Isolamento por projeto

A parte do sistema onde um erro custa mais caro.

Em resumo
  • Cada pessoa enxerga só os projetos em que está: os da conta própria e os do time.
  • Quem enxerga o quê é decidido por projeto, e o papel decide quem muda a configuração.
  • O filtro mora no acesso a dados, e não em cada consulta.

Todo projeto pertence a uma conta, e a conta continua dona dos dados. Só que a fronteira agora é o projeto: você vê os projetos da sua conta e os de outras contas em que entrou pelo time.

Por que não filtrar em cada consulta

Funciona enquanto todo mundo lembra. Um dia alguém escreve uma consulta nova e esquece, e aqui esquecer é entregar dado de outro cliente. Por isso o filtro fica onde não dá para esquecer.
