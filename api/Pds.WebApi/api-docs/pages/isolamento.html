Isolamento por projeto

A parte do sistema onde um erro custa mais caro.

Cada pessoa enxerga apenas os projetos em que está: todos os da conta própria, de que é dona, e os de outras contas em que entrou pelo time. Não é uma regra que cada consulta aplica: é uma propriedade do acesso a dados.

A conta continua dona dos dados — todo projeto pertence a uma —, mas deixou de ser a fronteira: quem enxerga o quê é decidido por projeto. E, dentro do projeto, o papel decide quem muda a configuração.

Por que não filtrar em cada consulta

Filtrar em cada método funciona enquanto todo mundo lembra. Um dia alguém escreve uma consulta nova e esquece — e aqui esquecer é entregar dado de outro cliente. O filtro precisa estar onde não dá para esquecer.

Nesta seção

Onde o filtro moraUma linha no contexto, e a lista de projetos que ela compara. As consultas que atravessam o filtroQuarenta e cinco, todas propositais: quarenta e três em repositório, cada uma num método, e as duas que montam o acesso. De onde vem o acessoQuem monta a lista de projetos da requisição, os dois papéis, por que 404 e não 403, e o que fica fora do filtro.
