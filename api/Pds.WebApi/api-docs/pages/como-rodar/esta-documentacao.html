Esta documentação

Páginas estáticas, servidas pela própria API.

Em resumo
  • Fica em Pds.WebApi/api-docs e abre na raiz do endereço da API, em qualquer ambiente.
  • Cada página é um fragmento de HTML, e a lista ROUTES monta o menu.
  • Editar uma página não pede rebuild: salve e atualize o navegador.

Ela e o Swagger (em /swagger) ficam abertos também em produção. Mostrar o desenho não abre nada: toda rota com dado continua pedindo sessão, chave do projeto ou token do relato.

Onde fica cada coisa

A pasta seria wwwroot; o nome diz o que ela guarda, e a raiz web é apontada em Program.cs.

  • index.html: a casca, com o menu lateral e a área de conteúdo.
  • assets/js/docs.js: o roteador. A lista ROUTES define o menu.
  • assets/css/docs.css: o estilo.
  • pages/<seção>.html: a abertura de cada seção, e pages/<seção>/<passo>.html, cada passo dela.
  • assets/js/swagger-back.js: o botão de volta na barra do Swagger, injetado pelo Startup.cs.

Os nomes não são genéricos de propósito: app.js ou styles.css colidiriam no cache com os de outro projeto na mesma origem.

Acrescentar uma página

  • Seção nova: crie pages/nome.html e adicione a entrada em ROUTES.
  • Passo novo: crie pages/nome/passo.html e acrescente o passo em children.

A ordem da lista é a do menu e a do rodapé. Com dotnet run, só mexer em ROUTES pede recarregar a página inteira. A página não tem <head> nem <body>: o primeiro <h2> vira o título e o <p class="lead">, o subtítulo.

Os blocos que você pode usar

Resumo no topo

div.resumo, com dois a quatro itens logo abaixo do subtítulo.

Cartões

div.cartoes, para assuntos paralelos lado a lado.

Abre com clique

details.mais, para o detalhe de quem vai mexer no código. Desliza ao abrir e ao fechar.

Notas

note why para o porquê, note warn para armadilha e note todo para o que falta.

O que a página ganha sozinha

O docs.js acrescenta, sem nada no HTML:

  • Barra de leitura: uma linha fina no topo mostra quanto da página já foi lido.
  • Voltar ao topo: um botão redondo aparece no canto depois de rolar um pouco.
  • Copiar código: todo bloco pre ganha o botão Copiar, que aparece ao passar o mouse.
  • Animações: os primeiros blocos chegam em sequência, e os de baixo aparecem ao rolar.

Quem pede menos movimento no sistema (prefers-reduced-motion) vê tudo parado, e a volta ao topo é imediata.
