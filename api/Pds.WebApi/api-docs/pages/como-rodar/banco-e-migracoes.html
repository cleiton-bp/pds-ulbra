O banco e as migrações

Um PostgreSQL hospedado, compartilhado pelo grupo.

Em resumo
  • Não há banco no docker-compose.yml, para ninguém migrar o lugar errado.
  • Migração aplicada vale para todos na hora: combine antes.

A string de conexão

  • Use o endereço externo. O interno só resolve de dentro da hospedagem; vale trocar por ele quando a API rodar lá.
  • No banco hospedado, SSL Mode=Require. A hospedagem recusa texto claro. A API não exige: o banco da produção, na rede interna, vai sem.
O banco é compartilhado

Combine com o grupo antes de rodar database update.

A produção tem banco próprio, na mesma máquina da API, e é migrada pelo deploy (deploy/scripts/implantar.sh) antes de a API nova subir.

Migrações

dotnet ef migrations add <Nome> --project Pds.Data --startup-project Pds.WebApi --output-dir Migrations
dotnet ef database update --project Pds.Data --startup-project Pds.WebApi
