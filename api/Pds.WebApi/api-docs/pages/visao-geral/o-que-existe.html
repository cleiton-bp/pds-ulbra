O que existe, e o que fica para depois

O que existe hoje, e o que está declarado para depois, cada item com a sua situação.

A configuração da ferramenta se edita pelo painel, como as outras: o botão em O botão, os textos e o tema do formulário em Formulário e os de depois do envio em Quem relata. São os campos que mudam a aparência e todos os textos do quadro na página do cliente, e se só um desenvolvedor conseguisse editá-los, eles não seriam configuração: configuração que existe e ninguém alcança é dívida que cresce calada.

O que fica para depois

Conferido no servidor não é o mesmo que barrado no navegador

A lista de bloqueados é conferida nas quatro rotas que a ferramenta usa (a aparência do botão, a configuração do quadro, a configuração de mídia e o envio do relato) e recusa na hora; os relatos que já tinham entrado vindos do bloqueado ficam marcados para o time manter ou apagar de vez. A de autorizados decide se o relato entra direto no Trabalho: fora dela (a lista começa vazia), o relato é recebido e fica retido em "Aguardando liberação" até o time permitir ou bloquear o endereço, avisado no sino.

Quem declara o endereço é o carregador, que é código nosso, e onde dá vale o que o navegador diz (o cabeçalho Origin na leitura do botão, e location.ancestorOrigins no quadro), então a chave copiada para outro site é pega. Quem chamar a API sem passar pela ferramenta declara o que quiser: o muro é o frame-ancestors, que precisa de um servidor servindo o documento do quadro, e é Planejado.

O que não se acrescenta depois

Isolamento e identificador público não são coisas que se acrescentam depois. Os dois atravessam toda tabela e toda consulta: adiar significa reescrever o acesso a dados quando já houver dado de cliente dentro.
