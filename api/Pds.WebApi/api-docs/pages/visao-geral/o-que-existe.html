O que existe, e o que fica para depois

O que existe hoje, e o que está declarado para depois, cada item com a sua situação.

A configuração da ferramenta se edita pelo painel, na tela Botão no site, como as outras. São onze campos que mudam a aparência e os textos do quadro na página do cliente, e se só um desenvolvedor conseguisse editá-los, eles não seriam configuração — configuração que existe e ninguém alcança é dívida que cresce calada.

O que fica para depois

Cada item leva uma de três marcas. Planejado vai ser construído. Adiado começou a ser construído e ficou para depois, por decisão. Continuidade é o que o produto pode vir a ter, fora do escopo atual — está declarado para não se perder.

Conferido no servidor não é o mesmo que barrado no navegador

A lista de endereços autorizados é conferida nas três rotas que a ferramenta usa: a configuração do quadro, a configuração de mídia e o envio do relato. Endereço declarado fora dela não abre a ferramenta e não grava relato. Projeto com a lista vazia aceita qualquer endereço — é o estado de quem ainda não restringiu.

Quem declara o endereço é o carregador, que é código nosso, então a chave copiada para outro site é pega. Quem chamar a API sem passar pela ferramenta declara o que quiser: o muro é o frame-ancestors, que precisa de um servidor servindo o documento do quadro, e é Planejado.

O que não se acrescenta depois

Isolamento e identificador público não são coisas que se acrescentam depois. Os dois atravessam toda tabela e toda consulta: adiar significa reescrever o acesso a dados quando já houver dado de cliente dentro.
