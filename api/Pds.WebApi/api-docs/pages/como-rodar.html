Como rodar

Precisa de .NET 10. Não precisa de banco local.

Todos os comandos rodam a partir da pasta api.

cd api

cp Pds.WebApi/Environment/.env.example Pds.WebApi/Environment/.env.local
# peça os valores a quem já roda o projeto

dotnet ef database update --project Pds.Data --startup-project Pds.WebApi
dotnet run --project Pds.WebApi

A API sobe em http://localhost:5080. Esta documentação fica na raiz e o Swagger em /swagger.

Não use a 5000 no macOS

O Receptor do AirPlay ocupa a 5000 e a 7000, no curinga *. O sistema até deixa a API subir em 127.0.0.1:5000 ao lado dele, mas quem atende a conexão depende da ordem em que cada um subiu — às vezes é a API, às vezes é o AirPlay. Intermitente é pior do que quebrado.

O sintoma é HTTP 403 no navegador, com a API rodando normalmente. Para confirmar quem respondeu, olhe o cabeçalho: Server: AirTunes entrega o AirPlay.

Dividir porta pede cuidado com o cache

Aplicações na mesma porta dividem a mesma origem no navegador: o cache, o localStorage e os cookies são os mesmos para todas. O CSS e o JavaScript de um projeto podem acabar servidos no lugar dos do outro quando os caminhos coincidem — a página mostra o nome do projeto errado, com o código certo no servidor.

Por isso os nossos assets têm nome próprio (docs.css, docs.js) e são servidos com no-cache.

Login com Google

O GOOGLE_CLIENT_ID sai do console do Google Cloud, em APIs e serviços → Credenciais → ID do cliente OAuth, tipo aplicativo web. Em desenvolvimento funciona com localhost; para o ambiente publicado é preciso ter o domínio antes.

Não há client secret aqui: quem faz o Sign-In é o painel, no navegador, e a API apenas confere o token recebido.
