Como rodar

Precisa de .NET 10. Não precisa de banco local.

Em resumo
  • Copie o .env.local, aplique as migrações e rode a API.
  • O Docker é opcional: sobe a fila e o armazenamento dos anexos.
  • Esta documentação e o Swagger ficam abertos, também em produção.

Todos os comandos rodam a partir da pasta api.

cd api

cp Pds.WebApi/Environment/.env.example Pds.WebApi/Environment/.env.local
# peça os valores a quem já roda o projeto

dotnet ef database update --project Pds.Data --startup-project Pds.WebApi
dotnet run --project Pds.WebApi

A API sobe em http://localhost:5080. Esta documentação fica na raiz do endereço da API e o Swagger em /swagger.

Docker é opcional

Sem a fila, a espera antes de quem relatou ver fica indisponível, o prazo do pedido de informação não encerra nada sozinho, o convite não sai e a exclusão de conta só se completa quando a pessoa entra de novo. Sem o armazenamento, o anexo fica desligado. O resto da API sobe inteiro.

cd api

docker compose up -d rabbitmq             # só a fila
docker compose up -d minio minio-init     # só o armazenamento
docker compose up -d --build              # tudo, com a API junto, na mesma 5080

O banco fica de fora porque é hospedado e compartilhado. O e-mail também: sai por um SMTP de fora, configurado no .env.local. Veja A fila, O armazenamento e O e-mail.

Não use a 5000 no macOS

O AirPlay ocupa a 5000 e a 7000, no curinga *. Com a API em 127.0.0.1:5000, às vezes responde ela, às vezes ele. O sintoma é HTTP 403, e o cabeçalho Server: AirTunes entrega o AirPlay.

Porta dividida e cache

Aplicações na mesma porta dividem o cache, o localStorage e os cookies do navegador. Por isso os nossos arquivos se chamam docs.css e docs.js e são servidos com no-cache.

As sondas de saúde

Duas rotas sem sessão, fora do Swagger, para a plataforma que hospeda a API (o Kubernetes, por exemplo):

  • GET /health/live, a vida: o processo responde. Nunca olha o banco.
  • GET /health/ready, a prontidão: 503 enquanto a API aquece (o modelo do EF e as primeiras conexões, menos de meio segundo) ou o banco não responde, e 200 depois.

Com o banco fora na subida, a API fica viva e não pronta, e tenta de novo sozinha, com espera crescente até 30 s.

Login com Google

O GOOGLE_CLIENT_ID sai do console do Google Cloud, em APIs e serviços → Credenciais → ID do cliente OAuth, tipo aplicativo web. Em desenvolvimento serve localhost; publicado, é preciso o domínio. Não há client secret: o painel faz o login, e a API só confere o token.
