O que cada camada carrega

CamadaContémNão pode conter
ApiBase Entidade base, repositório genérico, Unit of Work Nada do domínio
Domain Entidades, enums, interfaces, DTOs, view models; o catálogo de formatos de arquivo e a conferência dos bytes Acesso a banco, HTTP
Translation O motor: uma função pura e os valores que ela recebe Qualquer referência, inclusive a Domain
Data Contexto, mapeamentos, repositórios, migrações Regra de negócio
Service Regra de negócio, geração de chave, token, varredura de dado sensível, quem anexa o quê e quando Tipos de HTTP
Shared Registro de dependências, contrato JSON Regra de negócio
Workers Conexão com a fila, agendamento, os consumidores — o das esperas e o do e-mail Transação, consulta, regra
Storage Conexão com o armazenamento: assinar envio e leitura, ler os primeiros bytes, copiar exigindo o ETag, o nome do download Transação, consulta, regra — e o arquivo inteiro: só o primeiro quilobyte passa por ali
Email Conexão com o servidor SMTP: as opções da seção Smtp, montar a mensagem e entregá-la Transação, consulta, regra — e nova tentativa: a falha sobe, e quem chama decide
WebApi Controladores, middleware, configuração Regra de negócio, consulta direta — com uma exceção de propósito: o AccountMiddleware lê do banco quem é a pessoa e os projetos que ela enxerga, antes de qualquer serviço existir na requisição. Ver De onde vem o acesso.
